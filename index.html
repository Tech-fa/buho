Where the app runs

DigitalOcean creates a computer for you. Or use a computer you already have. Either way, we sign in with SSH and install the app there.

DigitalOcean key

DigitalOcean is the company that will run your app. You need a key from them so we can set it up for you.

On their website, create a key and choose Full Access. The picture shows the right choice. Copy the key and paste it below. We keep it on this computer only.

Your computer

We sign in with SSH on port 22 and install the app there. Use root, or a user that can run commands as root without a password. The private key must not ask for a password.

Email key

The app sends email through a service called Resend. Create a key on their website, paste it below, and save it. We keep it with the rest of your setup on this computer.

Sending address

When the app sends an email, this is the address people see it came from. It starts as notifications@resend.dev. Change it only if Resend is allowed to send from another address.

Sign-in email

This is the email address you will use to sign in and manage the app. Use an address you can open.

Where your app runs

Choose a place close to your team. If most people are in one city, choose that city. A closer place usually makes the app feel faster.

This list only shows places DigitalOcean can use right now. If the place you want is missing, it is not available. Choose another place from the list.

We will sign in to the computer you saved and install the app there. Leave this window open.

Your app is ready

Save a copy of your setup in a private place, such as a folder only you use. The copy includes your keys and the sign-in password. Do not email the file, and do not put it in a shared folder.

Download your data

This saves one zip file from the computer that runs your app. Inside it is a copy of the database and the files people uploaded. Keep the file private.

Use your own domain

Set up the domain you own, such as example.com, so people can open the app at an address you control. Choose Add domain, add the rows, then tell us the rows are in place.
